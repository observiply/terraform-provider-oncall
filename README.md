# terraform-provider-oncall

Terraform/OpenTofu provider for [oncall](https://github.com/observiply/oncall), built with [terraform-plugin-framework](https://github.com/hashicorp/terraform-plugin-framework).

## Resources

| Resource | What it is |
|---|---|
| `oncall_schedule` | An on-call schedule (name, timezone, owner team, sharing) |
| `oncall_schedule_layer` | A rotation layer/tier within a schedule (members, rotation length, handoff) |
| `oncall_schedule_notification_policy` | Escalation steps for a schedule |
| `oncall_trigger` | An alert ingest endpoint (payload template, auth; exposes `ingest_url` / `token`) |
| `oncall_trigger_targets` | Routing from a trigger to schedules/integrations per event |
| `oncall_integration` | An outbound integration, e.g. `outgoing_webhook` |

Read-only data sources: `oncall_team`, `oncall_teams`, `oncall_team_members`, `oncall_roles`, `oncall_resources`.

Reference setup: [`examples/complete/main.tf`](examples/complete/main.tf).

## Layout

```
main.go                     provider server entrypoint
internal/client/            generated from swagger.json — do not hand-edit
internal/provider/          schema, config, validation, auth probe
examples/                   consumed by tfplugindocs
docs/                       generated by tfplugindocs — do not hand-edit
templates/                  tfplugindocs overrides
.goreleaser.yml             release build matrix, checksums, signing
terraform-registry-manifest.json  protocol version 6.0
```

## Configuration

```hcl
provider "oncall" {
  endpoint = "https://oncall.example.com" # or ONCALL_ENDPOINT
  token    = var.oncall_token             # or ONCALL_TOKEN (Sensitive)
}
```

- `endpoint`: oncall base URL. The provider appends `/m2m/api/v1`.
- `token`: an oncall-issued API token. Expires (90d default, 365 max).

## Secrets

- `oncall_integration` outbound auth uses write-only attributes (`secret_wo` / `secret_wo_version`). Requires Terraform/OpenTofu >= 1.11.
- `oncall_trigger.token`

## Local development

```bash
go install .

cat >> ~/.tofurc <<'EOF'
provider_installation {
  dev_overrides {
    "observiply/oncall" = "/Users/<you>/go/bin"   # $(go env GOPATH)/bin
  }
  direct {}
}
EOF
```

Same block works in `~/.terraformrc`. Skip `tofu init` for this provider with the override active.

## Build / generate / test

```bash
go generate ./...        # regenerate internal/client + docs from swagger.json
go build ./... && go vet ./... && golangci-lint run
go test ./...            # unit tests
```

### Acceptance tests

The token must belong to an oncall admin; the suite manages the seeded "Demo Platform" team.

```bash
TF_ACC=1 \
TF_ACC_PROVIDER_NAMESPACE=hashicorp \
ONCALL_ENDPOINT=https://oncall.example.com \
ONCALL_TOKEN=oncall_pat_... \
  go test ./internal/provider/... -run TestAcc -v -timeout 20m
```

`TF_ACC_PROVIDER_NAMESPACE` is required under OpenTofu.

## Updating the vendored API spec

```bash
cp /path/to/oncall/docs/swagger.json internal/client/swagger.json
go generate ./...
git add internal/client/swagger.json internal/client/client.gen.go
```
